# Лабораторная работа N1

## Условие
Условие

1. Найти http сайт.
2. С помощью анализатора Wireshark собрать дамп трафика указанны сайтов.
3. С помощью инструмента tracert/traceroute определите путь до сайтов, найдите в дампе пакеты, ответственные за трассировку пути.
4. В дампе трафика найдите кадры канального уровня, пакеты сетевого уровня, МАС-адреса источника и цели, IP-адреса источника и цели. Найдите пакеты, ответственные за преобразование символьных имен в IP-адреса (как называется протокол?)
5. Найдите пакеты, отвечающие за установление безопасного сетевого соединения, (как называется протокол?)
6. Измерить задержки от начала выполнения запроса до получения первых данных от сайта, вносимые различными элементами сетевого стека, и совокупную задержку (из чего она складывается?)
